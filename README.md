# IT Dodges Paperwork — Model Showcase

Four browser-playable interpretations of the same game concept, presented as a small model comparison exhibit.

| Edition | Format | Scope |
|---|---|---|
| 5.6 Sol | Single HTML file | 45-second survival game |
| 6.1 Sol | Single HTML file | Polished arcade loop with lives and abilities |
| 6 Astra | Single HTML file | Multi-department runner with expanded movement |
| 6 Astra + Codex + assets | Structured game project | 12 sectors, bosses, progression, records, witnesses, and multiple endings |

## Play

Visit the GitHub Pages link in this repository's About section, then choose any edition from the gallery.

The three single-file originals are preserved unchanged. The Codex edition is a browser port of **Department Zero: The Last Human Ticket** and shares its generated art and authored level data.
